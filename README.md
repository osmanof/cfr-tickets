# cfr-tickets

Извлечение параметров поездки из текстового запроса с помощью технологии Conditional Random Field.

Модель принимает запрос на русском языке:

```text
билет из Минеральных Вод в Нижний Новгород с 11 июня до 15 июня
```

и выделяет из него основные параметры:

```text
Откуда:    Минеральные Воды
Куда:      Нижний Новгород
Начало:    11 июня
Конец:     15 июня
```

## Идея

Задача формулируется как разметка последовательности токенов. Для каждого слова CRF определяет один из BIO-тегов:

```text
B-FROM / I-FROM
B-TO / I-TO
B-DATE_FROM / I-DATE_FROM
B-DATE_TO / I-DATE_TO
O
```

Например:

```text
из       O
Казани   B-FROM
в        O
Москву   B-TO
с        O
12       B-DATE_FROM
июня     I-DATE_FROM
до       O
15       B-DATE_TO
июня     I-DATE_TO
```

Такой подход позволяет обрабатывать разные формы запроса, при которых порядок городов и дат может меняться, а вокруг полезной информации может находиться произвольный текст.

## Архитектура

```text
Текстовый запрос
      │
      ▼
Нормализация и токенизация
      │
      ▼
Извлечение признаков токенов
      │
      ▼
CRF sequence labeling
      │
      ▼
BIO-теги
      │
      ▼
Объединение сущностей
      │
      ▼
Нормализация городов и дат
      │
      ▼
FROM / TO / DATE_FROM / DATE_TO
```

Для каждого токена используются само слово, его lowercase-представление, суффиксы, признаки регистра и цифр, а также соседние токены.

После CRF выполняется постобработка, при которой составные сущности объединяются, а города и даты сопоставляются со словарями. Для обработки неточного написания используется расстояние Левенштейна (это причём очень даже неплохо сработало).

## Обучение

Обучающая выборка генерируется из шаблонов запросов, списков городов, дат и дополнительных фраз. По умолчанию генератор создает 150 000 примеров.

```bash
cd src
python generate_dataset.py
python train.py
```

Обучение выполняется через `sklearn-crfsuite`. Данные делятся на train/test в соотношении 80/20, после чего обученная модель сохраняется в `models/model.pkl`.

> `dataset.py` использует `pandas`. Если библиотека отсутствует в окружении, установите её отдельно.

## Запуск

```bash
git clone https://github.com/osmanof/cfr-tickets.git
cd cfr-tickets

pip install -r requirements.txt

cd src
python test.py
```

После загрузки модели можно вводить запросы прямо в консоль:

```text
хочу попасть в Казань из Махачкалы от завтра до пятницы
```

Модель выделит найденные параметры маршрута и дат.
