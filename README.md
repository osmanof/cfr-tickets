# О проекте

Модель, основанная на архитектуре CFR. Принимает на вход предложения по типу

    билет из Минеральных вод в Нижний Новгород на 11 июня до 15 июня

и возвращает ответ

    Откуда:		Минеральные Воды
    Куда:		Нижний Новгород
    Начало:		11 июня
    Конец:		15 июня

# Запуск

    pip3 install requirements.txt

    cd src
    
    python3 test.py
